# 2026-03-19

- Reproduced local HTTP control against `vibe-mcp` and found a stack overflow during session teardown.
- Root cause: `transport.onclose` called `server.close()`, which recursively closed the same transport again.
- Patched both `src/server.ts` and `dist/server.js` to remove the recursive `server.close()` call from `transport.onclose`.
- Re-tested local HTTP control after the fix: MCP health succeeded, `tools/list` returned 45 tools, and `list_pages` returned live browser tabs including TradingView and Telegram.
